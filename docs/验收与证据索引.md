## 四、需要结合解释的历史字段

1. **program-result.json的success=false**：历史下载脚本把WFI的SLEEPING误判为运行失败；完整Flash与选项字节校验已通过。后续独立运行核验与真实CAN记录证明恢复，旧结果不改写。
2. **真实GUI原报告simulated=true**：当时直接使用Qt5.12 isVirtual，真实SLCAN也被判为虚拟。独立审计、sysfs证据和后续分类测试单独记录。
3. **hardware_verified=false**：自动引擎只提供协议观察，不自动判断实物接线或用户看到的灯。总体真机结论由多项证据合并得出。
4. **physical_unplug_user_confirmation=false**：USB测试程序不会读取聊天确认。原始字段保留，用户实际拔插与VMware操作记录在独立acceptance.json。
5. **断开时connected=true但online=false**：旧Qt对象的连接状态可能未立即变化；设备可用性应结合接口是否存在、有效心跳与写入结果判断。
6. **历史“尚未验证”**：9月23日软件报告和9月24日构建报告只描述当时状态，不代表最终状态。
