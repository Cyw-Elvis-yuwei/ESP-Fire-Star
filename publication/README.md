## 材料与改动

- 包含Qt/CLI/核心判定、STM32业务与固定厂家HAL、测试、工具、项目报告和全部现有项目图片。
- 公开证据文本替换个人绝对目录、局域网地址及设备唯一标识；数值、布尔结果、协议报文和成功/失败结论不变。
- 图片原像素保留，新增真实can0心跳在线截图和独立副本7步回归通过截图：前者仅接收心跳，后者实际发送7条命令并恢复初始LED状态；没有重复整套故障验收。
- 芯片完整备份、原始聊天、采购和文档历史ZIP只本地保留，见[省略材料说明](OMITTED.md)。
- 两处目标选择参数公开化：DAP通过CANBENCH_DAP_ID选择，USB恢复脚本通过CANBENCH_CANABLE_SERIAL选择；未指定时不会接管任意设备。主机测试脚本另改用PATH中的clang.exe默认值，可用-Clang指定路径；业务逻辑和固件未改变。

历史阶段报告是在当时环境下验收；公开副本的检查单独记录在[validation.json](validation.json)。源码构建验证与真机照片/截图不互相替代，未为发布重新烧录或重复拔插。
